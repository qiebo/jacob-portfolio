# JACOB / Portfolio

这是一个面向求职的公开作品集展示仓库。

仓库只呈现经过整理的项目背景、产品外观、交互截图、架构说明、工作成果与履历证据，不包含桌面数智人、X 书签知识库、公司 Skill 或其他项目的源代码。

## 页面结构

- `index.html`：作品集首页
- `cases/desktop-digital-human.html`：桌面数智人一体机案例
- `cases/x-bookmarks.html`：X 书签知识库案例
- `cases/ai-workflows.html`：AI 工作流与 Skill 案例
- `cases/recognition.html`：职业履历与荣誉
- `docs/content-map.md`：后续内容补充清单

## 公开原则

1. 先展示问题、判断、成果和验证证据，再决定是否提供进一步资料。
2. 项目源码、内部 Prompt、客户文件、采购链接、账号、Token、IP 地址和未脱敏截图不进入本仓库。
3. 原始资料保留在本地工作目录，公开仓库只接收经过审核的展示副本。
4. 每个案例明确区分个人贡献、团队贡献、已交付成果和概念探索。

## 本地预览

直接打开 `index.html` 即可查看静态页面。后续发布到 GitHub Pages 后，在线页面作为招聘者入口，仓库文件作为补充说明。

## 当前状态

当前版本是公开展示框架。项目图片、演示视频、脱敏后的案例文案和履历证据将在逐项确认后补充。
