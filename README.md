# JACOB / Portfolio

个人作品集网站，集中呈现 AI 应用、软硬件原型、知识系统、AI 工作流与工作成果。

在线地址：<https://qiebo.github.io/jacob-portfolio/>

## 设计风格

宋式减法美学 × 克制科技感：

- **底色**：素笺白（偏暖的米白），搭配极细电路纹理与宣纸颗粒质感
- **主色**：靛青（标题、链接、强调）
- **点睛色**：赤金（印章 logo、数字编号、hover 微光）
- **字体**：Noto Serif SC（宋体标题）+ Noto Sans SC（黑体正文）+ Space Grotesk（英文数字）
- **科技感元素**：卡片边缘微光描边、电路纹理背景、克制的 hover 动效
- **古风元素**：大量留白、宋体大标题、印章式 logo、极细分割线

## 内容结构

- `index.html`：作品集首页与个人定位
- `cases/`：独立案例页
  - `desktop-digital-human.html` — 桌面数智人一体机（软硬件协同）
  - `child-ai-companion.html` — 逗包 · 儿童 AI 伴侣（全栈 AI 应用）
  - `x-bookmarks.html` — X 书签知识库（信息架构）
  - `ai-workflows.html` — AI 工作流与 Skill（方法产品化）
  - `recognition.html` — 履历与工作成果
- `assets/`：页面使用的图片素材
- `styles.css`：网站视觉与排版（宋式美学 + 科技感）
- `script.js`：页面基础交互

每个案例围绕四个问题展开：做了什么、为什么这样做、我贡献了什么、留下了什么结果。
