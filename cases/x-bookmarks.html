01 / PROJECT IDEA

重点不是收藏了多少，而是能不能再次找到并用起来。

这个项目把“收藏”看成一个长期输入系统：先稳定地留下内容，再用清晰的结构降低查找成本，最后让知识回到研究、写作与工作判断中。

Input长期书签
Structure主题 / 标签 / 摘要
Action检索 / 回顾 / 引用
Value让收藏产生复利

02 / SYSTEM DESIGN

把模糊的“我记得看过”，变成清楚的检索路径。

01

采集

先把链接、标题、作者、日期和原始上下文保留下来，避免知识从收藏开始就丢失。

02

组织

用主题、内容类型、标签和摘要建立层次，让分类逻辑可以被解释、被调整。

03

使用

从一个具体问题回到知识卡片，完成阅读、比较、引用或继续沉淀。

03 / CASE VALUE

这是一个关于信息复利的个人实验。

当收藏不再是浏览历史的终点，而成为可查询的素材库，个人学习、行业观察和项目准备就拥有了一条稳定的回路。

  • 让长期收藏从“堆积”进入“组织”
  • 让主题与标签服务于真实问题
  • 让检索结果可以继续写作、分享和复用
  • 让知识系统随着使用而不是随着时间失效
